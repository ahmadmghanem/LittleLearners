# Little Learners 2.0

Native Android educational game for children.

Features:
- A-Z letters with examples
- Numbers 1-20
- 32 colors
- Animals and fruits as visual learning cards
- English Text-to-Speech
- Easy / Medium / Hard difficulty
- Stars, levels and saved progress
- Progress survives app restarts using SharedPreferences
- No internet required

Open in Android Studio and build an APK:
Build > Build APK(s)
